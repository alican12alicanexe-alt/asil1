# THE SIMULATOR NEEDS NONE OF THIS.
#
# The simulator and its tkinter schematic view run on a bare Python install with
# no packages at all - that is a deliberate constraint, so the project works on a
# locked-down machine where pip may be blocked. Running a scenario, checking one,
# comparing systems and writing a trace all hold to it.
#
# Two things sit outside that. The charts are matplotlib's, so graph.py and
# _plot_curves.py need it installed; and ui_qt.py is built on Qt. Neither is on
# the path of a run - ui_tk.py is the front end that needs nothing at all.
#
# All of these install without admin rights:
#     pip install --user -r requirements-optional.txt

PyYAML>=5.4      # a faster, fully-featured YAML parser; there is a built-in
                 # fallback subset parser (trainsim/scenario/minyaml.py) if absent
matplotlib>=3.5  # draws every chart: graph.py and _plot_curves.py need it, and
                 # nothing else does - a run, a --check and a --log spreadsheet
                 # all still work with none of these installed
pygame>=2.1      # an alternative rendering backend, if smoother zoom/pan is wanted
PySide6-Essentials>=6.5
                 # the Qt front end, ui_qt.py - the comparison page plus the line
                 # builder. ui_tk.py does the comparison with no packages at all,
                 # so this buys drawing quality and the builder, not the numbers.
                 # PySide6-Addons is NOT needed (3D, multimedia, WebEngine)
